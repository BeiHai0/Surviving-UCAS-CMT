# 第三章 计算机科学基础

## 本章导读

讨论量子加速之前，必须先明确“什么是计算”和“快多少”。本章用图灵机建立通用计算模型，再用时间、空间与问题规模定义计算复杂度，为比较经典算法和量子算法提供共同尺度。

## 学习目标

- 解释图灵机的组成与一步计算。
- 区分判定问题、语言、算法和机器。
- 使用大 $O$ 记号估计算法资源。
- 区分 P、NP、BPP 与 BQP 的基本含义。
- 判断量子加速声明是否采用公平的输入与成本模型。

## 预备知识

集合 $\Sigma^*$ 表示字母表 $\Sigma$ 上所有有限字符串。判定问题只回答“是”或“否”，可等价表示为语言 $L\subseteq\Sigma^*$：输入 $x\in L$ 时接受，否则拒绝。

## 第1节 图灵机、计算复杂度

### 1.1 图灵机的直觉

图灵机（Turing machine, TM）是一种极简计算模型：无限纸带保存符号，读写头每次读取一个格子，有限控制器依据当前状态和符号进行写入、移动与状态转换。它不追求工程效率，而是精确定义“算法可计算”。

### 1.2 形式定义

确定型图灵机可由状态集 $Q$、输入字母表 $\Sigma$、纸带字母表 $\Gamma$、转移函数 $\delta$、初态及接受/拒绝态描述。转移函数形如

$$
\delta:Q\times\Gamma\to Q\times\Gamma\times\{L,R}.
$$

它说明在某状态读到某符号时，应进入哪个状态、写什么符号、向左还是向右移动。

### 1.3 可计算性与停机

若存在一台图灵机对所有输入都停机并给出正确答案，则该判定问题可判定。存在不可判定问题，经典例子是停机问题：不存在通用算法能判断任意程序对任意输入是否会停机。量子计算改变某些问题的效率，但并不会把不可计算问题普遍变为可计算。

### 1.4 计算复杂度

令输入长度为 $n$。算法最坏情况下使用的步数 $T(n)$ 是时间复杂度，访问的存储单元数 $S(n)$ 是空间复杂度。若 $T(n)\le c g(n)$ 对充分大的 $n$ 成立，则写作 $T(n)=O(g(n))$。

多项式时间通常被视为“有效计算”的理论基准。常见复杂度类包括：

| 类 | 直观含义 |
| --- | --- |
| P | 确定型经典机可在多项式时间求解 |
| NP | “是”实例的证据可在多项式时间验证 |
| BPP | 随机经典算法以有界错误概率在多项式时间求解 |
| BQP | 量子算法以有界错误概率在多项式时间求解 |

BQP 中常取成功概率至少 $2/3$；通过独立重复和多数表决可降低错误概率。

### 1.5 查询复杂度与电路复杂度

黑盒算法常计算查询次数，即调用 oracle 的次数。完整运行成本还包含制备、普通门、测量和纠错。只比较查询次数时，应明确说明这是查询复杂度而非总时间复杂度。

### 1.6 典型例题

**题目：** 某算法对长度 $n$ 的输入执行 $3n^2+5n+7$ 步，求渐近时间复杂度。

**思路：** 大规模时最高次项主导增长。

**解答：** 存在常数 $c$ 使充分大 $n$ 时 $3n^2+5n+7\le cn^2$，所以复杂度为 $O(n^2)$；也可更精确写为 $\Theta(n^2)$。

**结果检查：** 低次项和常数不会改变渐近增长阶。

### 1.7 常见误区

- NP 不是“非多项式”的缩写，也不等于“不可解”。
- 指数加速必须比较同一问题、输入模型和误差标准。
- $O(n^2)$ 是渐近上界，不代表每个输入恰好运行 $n^2$ 步。
- 量子叠加不能被逐项读出，不能简单理解为同时得到 $2^n$ 个答案。

## 本章小结

图灵机使“算法”成为可严格讨论的对象，复杂度理论则研究资源随输入规模如何增长。量子算法的优势通常表现为查询复杂度或时间复杂度的改善，但必须计入数据访问、精度、成功概率等条件。BQP 描述可由量子计算机以多项式时间和有界错误求解的问题。

## 练习题

### 概念理解

1. 为什么需要抽象计算模型，而不能只比较两台具体计算机的运行秒数？
2. NP 的定义为什么强调“验证”而非“求解”？

### 基础计算

3. 将 $7n^3+2^n$ 写成合适的渐近复杂度。
4. 一个成功率为 $2/3$ 的算法独立运行三次并多数表决，失败概率是多少？

### 综合应用

5. 某量子算法只需 $O(\sqrt N)$ 次 oracle 查询，而经典算法需 $O(N)$ 次。说明在宣称实际平方加速前还需比较哪些成本。

## 练习题参考答案

1. 具体秒数依赖硬件、语言和实现；抽象模型用随输入规模增长的资源建立可迁移、公平的比较。
2. NP 的“是”实例存在多项式长度证据，并可被确定型算法在多项式时间验证；这不自动给出寻找证据的高效方法。
3. 指数项最终支配任意固定次数多项式，所以为 $\Theta(2^n)$。
4. 多数表决失败意味着至少两次失败。设单次失败率为 $1/3$，则概率为 $3(1/3)^2(2/3)+(1/3)^3=7/27$。
5. 还需比较 oracle 的实现成本、状态制备、普通门数与深度、测量重复次数、纠错开销以及经典最佳算法和数据访问模型。
