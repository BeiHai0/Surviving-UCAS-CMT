# LaTeX 讲义约定

- 所有章节的行间公式均使用自动编号。使用 `equation`、`align`、`gather` 等不带星号的 AMS 环境；多行 `align` 中每行自动编号。
- 沿用模板的按节编号设置 `\numberwithin{equation}{section}`，编号形如 `(3.1.1)`。不要用 `\tag` 手动编号，也不要用 `\notag`、`\nonumber` 隐藏编号。
- 行内公式不编号；矩阵、分段函数等内部结构仍放在外层编号环境中，不单独编号。
- 此约定适用于现有及以后新增的 LaTeX 章节，不改变 Markdown 原稿的公式格式。
- 用户自行编译。除非用户另有明确要求，不运行 LaTeX 编译器或生成 PDF。
- 数学公式中可见的圆括号、方括号、花括号均用配对的 `\left`、`\right`。不要修改命令参数的分组花括号；`bmatrix`、`cases` 等环境自身提供的定界符无需重复添加。跨行或跨对齐单元时必须保证每段定界符配对。
- 群名直接用 `\mathrm{SO}`、`\mathrm{SU}`、`\mathrm{GL}` 等，不定义或使用 `\SO` 等简写；数域直接用 `\mathbb{R}`、`\mathbb{C}`、`\mathbb{Z}`、`\mathbb{N}`，不使用 `\R` 等简写。
- 数值比较用 `\leqslant`、`\geqslant`；子群关系保留 `\leq`、`\geq`，不可机械替换。
- 数学加粗用 `\bm{...}`，模板加载 `bm` 包；希腊字母允许使用 `\mathbf`，但优先用能够正确加粗的 `\bm`。正文加粗仍使用 `\textbf`。
- 以 `群论.md` 为原文依据，保留原来的表述、术语、记号、证明思路与步骤顺序，不仅为了形式化、精简或改写风格而重写。必要的补充单独标明；确有错误时仅作最小修正，并在同目录 `勘误.md` 中记录位置、原文问题、修正与理由。不要把可接受的记号约定或纯排版调整列作数学错误。
